# MIDAS Documentation

Welcome to the documentation for **MIDAS**  
*(MoM Integral-equation Domain-decomposition for Arbitrarily-shaped Scatterers)*.

MIDAS is a numerically efficient 3D full-wave model for electromagnetic (EM) scattering from complex-shaped scatterers. The main code is written in FORTRAN and parallelized using MPI. Several MATLAB tools are provided to prepare inputs and process outputs.
