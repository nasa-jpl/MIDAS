
# Frequently Asked Questions (FAQ)

**Q1: Can I run MIDAS without MATLAB?**  
A: Yes, but MATLAB simplifies input preparation and output visualization.

**Q2: How many MPI processes should I use?**  
A: Depends on problem size. Start with 2-4 cores for testing and scale up for large simulations.

**Q3: Is the code compatible with Windows?**  
A: The core FORTRAN code is Unix/Linux optimized. Windows users can use WSL or a Linux VM.
