MIDAS (MoM Integral-equation Domain-decomposition for Arbitrarily-shaped Scatterers) is a numerically efficient 3D full-wave model for electromagnetic (EM) scattering from complex-shaped scatterers.
The main code is written in FORTRAN and is MPI parallelized. Several tools, written in MATLAB, are also provided to prepare and write the FORTRAN code inputs (shape, dielectric composition, simulation data files, etc.), or read and
display its outputs (scattered fields, scattering matrices and efficiency factors, etc.)
